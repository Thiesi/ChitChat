# ChitChat v3.2.1

`v3.2.1` is a cosmetic update on top of `v3.2.0`. It tidies up the Operational settings page. It adds no database migration and no configuration.

## Project status: feature-complete

This release does not change [project status](../README.md#project-status-feature-complete). ChitChat remains feature-complete. See [`docs/roadmap.md`](../roadmap.md).

## Changed

- **Operational settings layout.** ([#138](https://github.com/Thiesi/ChitChat/pull/138))
  - The maintenance lockdown message has a three-line box that spans the card, beside a narrow On/Off switch.
  - Saving the policy is a bar under its cards, with when it last changed, instead of a card in a row of its own.
  - The application name sits beside registration protection instead of filling a full-width card.
  - Cards in a row share one height, and headings sit closer to their content.
  - Phones still show everything in one column.

Only markup and styles changed. Every setting works as before.

## What to evaluate

Operators staging this release should open Operational settings on a wide screen and a phone, and check that:

- saving the lockdown, the policy, the application name and registration protection still works;
- existing behaviour elsewhere is unaffected.

## Database changes

None.

## Upgrade from v3.2.0

1. Deploy `v3.2.1` source.
2. Run:

   ```sh
   composer install --no-dev --classmap-authoritative
   composer migrate
   ```

   `composer migrate` reports nothing to apply.
3. Verify `/health.php`, `/ready.php`, and the Operational settings page.

Upgrading from before `v3.2.0` also applies that release's migration, `0039_guest_access.sql`; back up first and see its notes.

Follow `INSTALL.md`.
