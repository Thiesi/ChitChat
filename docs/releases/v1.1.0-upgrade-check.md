# v1.1.0 upgrade verification

This temporary release-branch note exists to make the exact upgrade boundary machine-reviewable during the release pull request.

- Supported predecessor: `v1.0.0`
- Target version: `v1.1.0`
- Forward migrations: `0010` through `0013`
- Required backup unit: PostgreSQL plus attachment storage together
- Rollback method: restore the matching pre-upgrade database and attachment backup
- Required browser gates: Chromium, Firefox, and WebKit
